# سُقيا — اطلب صهريجك 🚛💧

تطلب صهريج ماي لين باب بيتك في سلطنة عُمان:

1. تختار الولاية، وحجم الصهريج (جالون)، ونوع الماي (شرب / استخدام).
2. تحدد موقعك بضغطة أو تكتب العنوان، وتختار الوقت.
3. تشوف الصهاريج اللي تغطي منطقتك مع أسعارها، وتطلب على الواتساب، والرسالة جاهزة فيها الموقع والكمية.

## السوّاقين والأسعار
كلهم في ملف `drivers.json`. أي سايق عليه `"demo": true` تجريبي، وطلبه ما يروح لأحد.
لإضافة سايق حقيقي: الاسم، رقم الواتساب، المناطق، الأنواع، والسعر لكل حجم.

`admin.whatsapp` رقم إدارة سُقيا اللي توصله طلبات تسجيل السوّاقين.

النسخة القديمة من سُقيا (الموردين والقوارير) محفوظة في مجلد `old/`.

## المناطق
كل محافظات وولايات السلطنة موجودة في `drivers.json` تحت `governorates`.
في خانة `areas` لكل سائق اكتب أسماء الولايات اللي يوصلها (مثل `"صلالة"`)،
أو اكتب `"gov:ظفار"` لو يغطي المحافظة كاملة.

## قاعدة البيانات (Supabase)
- `supabase/setup.sql`: انسخه في Supabase ← SQL Editor ← Run (مرة وحدة).
- `config.js`: رابط المشروع و«المفتاح العام» (publishable). لا تحط فيه مفتاح secret أبدًا.
- السايق يسجّل من زر «أنا سايق» ويطلع له رمز دخول، ويقدر يعدّل أسعاره ويحط نفسه متوفر أو مشغول.
- صفحة الإدارة: `admin.html`. أول مرة تختار فيها رمز المدير، وبعدها توافق على السواقين أو توقفهم.
- لين يتسجّل أول سايق ويتعتمد، يظهر السواقين التجريبيين من `drivers.json`.
