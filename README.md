# سُقيا

تطبيق يربط موردي الماء (الشركات والمتاجر والوايتات) بالمستهلكين في كل محافظات وولايات سلطنة عُمان.

- **المستهلك:** يختار ولايته، يتصفح الموردين، يطلب قوارير وجوالين وتعبئة ووايتات، يحدد موقع التوصيل (بيت، مكتب، شركة، وزارة) مع اللوكيشن، ويدفع بالبطاقة أو التحويل البنكي أو نقداً.
- **المورّد:** يستقبل الطلبات، يفتح لوكيشن الزبون في الخرائط، يؤكد التحويلات، ويدير المنتجات والأسعار ومناطق التغطية.
- عرض ثلاثي الأبعاد للمنتجات.

> نسخة تجريبية: البيانات محفوظة على الجهاز، والدفع بالبطاقة تجريبي ولا يخصم أي مبلغ.
